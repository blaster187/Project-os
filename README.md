# Project OS V3

Prototype V3 de Project OS — une interface claire et futuriste pour visualiser des projets, décisions, notes et conversations IA sans se perdre dans de longues pages verticales.

## Lancer localement

```bash
npm install
npm run dev
```

## Déployer sur Vercel

1. Importer ce dépôt dans Vercel.
2. Framework preset: **Vite**
3. Build command: `npm run build`
4. Output directory: `dist`
5. Deploy.

## Inclus dans cette V3

- Dashboard blanc / minimaliste
- Sidebar de projets
- Recherche
- Vue carte relationnelle
- Vue liste
- Progression par projet
- Activité récente
- Module "Project AI" simulé
- Création locale de nouveaux projets
- Responsive mobile
- Données de démonstration pour Project OS, EdgeLab, Wangsta to Gangsta et Eliot

## Prochaine étape recommandée

Connecter une vraie base de données (Supabase) puis brancher l’API OpenAI pour transformer automatiquement les conversations et notes en noeuds structurés.
